# Task: Rust 하네스 관리 앱 첫 버전
- 상태: 확정
- 확정: boo 2026-11-17 (거기다 해봐 / Jira 없이 진행 / 앱 실행 위임에 모델 적용)
- 관련: 개인 프로젝트, 사용자 요청으로 Jira 없이 진행

## 범위
- macOS 우선, egui/eframe으로 화면과 앱 로직을 Rust로 작성한다.
- 기존 Python 하네스는 연동 대상으로 유지한다. 하네스 전체 Rust 이식은 포함하지 않는다.
- 기존 미커밋 작업은 수정하지 않는다. 앱은 별도 디렉터리에 둔다.

## 완료 조건
- [ ] **T-01** 로컬 Git 레포를 등록·제거할 수 있고 앱 재시작 후 목록이 유지된다.
- [ ] **T-02** 선택한 레포의 하네스 도입 상태와 누락 설정을 표시한다.
- [ ] **T-03** 전역·레포별 교차 위임 모드와 전역 중지를 조회·저장하고 실제 적용값을 표시한다.
- [ ] **T-04** Claude·Codex 교차 위임 후보의 모델·effort를 저장하고 Boorstar에서 실행하는 다음 위임에 적용하며 기존 기본값을 유지한다.
- [ ] **T-05** 선택한 레포의 루프 단계·검증 결과·최근 계측을 갱신하고 마지막 관측 시각과 데이터 없음을 구분한다.
- [ ] **T-06** 기간·레포별 검증 성공·실패와 위임 결과를 집계하고 수집된 모델·토큰 정보만 표시한다.
- [ ] **T-07** 잘못된 설정·누락 파일·명령 실패를 화면에 알리고 기존 설정과 무관한 필드를 보존한다.
- [ ] **T-08** macOS에서 앱을 실행해 한글 표시, 레포 선택, 설정 저장, 모니터링·분석 화면 전환을 확인한다. [수동]
